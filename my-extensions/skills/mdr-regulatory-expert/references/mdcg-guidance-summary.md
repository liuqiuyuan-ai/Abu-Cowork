## MDCG Overview

### What is MDCG?
The Medical Device Coordination Group is composed of experts from EU member states, responsible for:
- Developing guidance documents
- Coordinating interpretations
- Supporting consistent implementation

### Guidance Document Types
- **MDCG**: Full guidance documents
- **Guidance on**: Detailed guidance
- **Position papers**: Regulatory positions
- **Work groups**: Working group outputs

### How to Use MDCG Documents
- Reference for interpretation
- Support compliance demonstration
- Industry best practice
- Not legally binding but influential

## Classification Guidance

### MDCG 2019-11: Software Classification

#### Key Points
- Software classification follows rules with modifications
- Drive or influence devices: Class of device
- Standalone software: Based on purpose
- Clinical decision rules:
  - Information only: Class I/IIa
  - Drive/treatment: Class of device
  - Critical decisions: Class IIb/III

#### Application
- Apply to all software devices
- Consider intended use carefully
- Document classification rationale

### MDCG 2019-16: Borderline Classifications

#### Purpose
- Clarifies classification of borderline products
- Product-specific guidance
- Updates as needed

## Clinical Evaluation Guidance

### MDCG 2020-13: Clinical Evaluation Assessment

#### Assessment Criteria
- CER structure and content
- Equivalence demonstration
- Literature search methodology
- PMCF adequacy

#### Common Deficiencies
- Incomplete equivalence justification
- Poor literature search documentation
- Missing PMCF integration

### MDCG 2020-6: Adequate PMCF

#### PMCF Plan Requirements
- Defined activities
- Clear objectives
- Appropriate methods
- Evaluation criteria

#### Assessment Criteria
- PMCF plan completeness
- Activity justification
- Integration with PMS

### MDCG 2020-8: Equivalent Devices

#### Equivalence Criteria
- Clinical: Same intended use, similar patient population
- Technical: Similar design, materials, specifications
- Biological: Same materials in contact with tissues

#### Demonstration Requirements
- Comprehensive comparison
- Scientific justification
- Gap analysis
