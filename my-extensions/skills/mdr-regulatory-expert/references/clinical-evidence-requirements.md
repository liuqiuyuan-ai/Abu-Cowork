## Clinical Evidence Overview

### Definition
Clinical evidence is the clinical data and its appraisal and analysis demonstrating conformity with GSPR.

### Components
- **Clinical data**: Safety and performance data from clinical use
- **Clinical evaluation**: Systematic process of assessing clinical data
- **Clinical evidence**: Output of clinical evaluation demonstrating GSPR compliance

### Level of Clinical Evidence Required
- Proportional to device risk class
- Higher risk = More comprehensive evidence required
- Novel devices = Higher evidence requirements

## Clinical Evaluation Process

### Step 1: Clinical Evaluation Plan (CEP)

#### CEP Content
- Scope and objectives
- Device description and intended purpose
- Equivalence claims (if applicable)
- Clinical data sources to be reviewed
- Appraisal and analysis methodology
- Acceptance criteria
- PMCF considerations

#### CEP Approval
- Must be approved before clinical evaluation
- Part of technical documentation
- Updated throughout device lifecycle

### Step 2: Clinical Data Collection

#### Data Sources
1. **Clinical investigations**
2. **Scientific literature**
3. **Post-market clinical follow-up data**
4. **Post-market surveillance data**
5. **Published clinical experience**

### Step 3: Appraisal of Clinical Data

#### Appraisal Criteria
- Relevance to intended purpose
- Scientific validity
- Methodological quality
- Statistical significance
- Data completeness

#### Appraisal Tools
- MEDDEV 2.7/1 Rev 4 appraisal framework
- GRADE methodology
- Cochrane risk of bias tools

### Step 4: Analysis of Clinical Data

#### Analysis Requirements
- Adequacy of data for demonstrating GSPR
- Consistency of data
- Relevance to intended purpose
- Assessment of residual risks
- Benefit-risk determination

### Step 5: Clinical Evaluation Report (CER)

#### CER Content
- Executive summary
- Scope of evaluation
- Device description
- Equivalence assessment (if applicable)
- Clinical data identification
- Appraisal results
- Analysis and conclusions
- PMCF plan reference

## Clinical Data Sources

### 1. Clinical Investigations

#### Requirements
- Conducted per ISO 14155
- Ethics committee approval
- Competent authority notification (if applicable)
- Informed consent obtained
- Clinical investigation plan documented

#### When Required
- Novel devices
- Significant design changes
- Insufficient literature data
- Class III implantable devices (certain)

### 2. Scientific Literature

#### Requirements for Acceptable Literature
- Systematic search methodology
- Relevant to device and intended use
- Quality appraisal conducted
- Results applicable to device

#### Literature Sources
- PubMed/MEDLINE
- Embase
- Cochrane Library
- Conference proceedings
- Grey literature (with caution)

### 3. Post-Market Data

#### Acceptable Post-Market Data
- PMCF study results
- Complaint data analysis
- Incident reports
- Published clinical experience
- Registry data

## Literature Review Requirements

### Systematic Approach

#### Step 1: Define Search Strategy
- Define research questions
- Identify relevant databases
- Define search terms
- Define inclusion/exclusion criteria

#### Step 2: Conduct Search
- Document search methodology
- Search date and time frame
- Number of records identified
- Search terms used

#### Step 3: Screen Records
- Title and abstract screening
- Full-text review
- Document screening decisions

#### Step 4: Appraise Data
- Apply appraisal criteria
- Document quality assessment
- Exclude low-quality data

#### Step 5: Extract and Analyze
- Data extraction
- Synthesis of results
- Gap analysis

### Equivalence Demonstration

#### Criteria for Equivalence
- **Clinical**: Same intended purpose, similar body site, similar patient population
- **Technical**: Similar design, materials, operating principles, conditions of use
- **Biological**: Similar materials/substances in contact with tissues

#### Documentation Required
- Comprehensive equivalence table
- Scientific justification
- Gap analysis identifying differences
- How differences are addressed

## PMCF Requirements

### Purpose
Proactively collect clinical data post-market to:
- Confirm safety and performance
- Identify previously unknown risks
- Update benefit-risk assessment
- Identify systematic misuse

### PMCF Plan Requirements

#### Plan Content
- Objectives of PMCF activities
- Methods to be used
- Data sources
- Milestones and timelines
- Evaluation criteria
- Integration with PMS

#### PMCF Activities
- PMCF studies
- Registry participation
- Literature review
- Post-market investigations
- Real-world evidence collection

### PMCF Evaluation Report

#### Report Content
- Summary of PMCF activities
- Results and analysis
- Conclusions on safety and performance
- Impact on clinical evaluation
- Recommendations

#### Reporting Frequency
- Updated as PMCF activities complete
- Part of PSUR
- Submitted to Notified Body

## Common Issues

### Top Clinical Evaluation Deficiencies

1. **Inadequate Literature Search**
   - Search strategy not documented
   - Databases not comprehensive
   - Inclusion/exclusion criteria unclear

2. **Poor Equivalence Justification**
   - Differences not addressed
   - Equivalence table incomplete
   - Biological equivalence not demonstrated

3. **Insufficient Appraisal**
   - Quality appraisal not conducted
   - Appraisal criteria not defined
   - Results not documented

4. **PMCF Plan Gaps**
   - PMCF activities not defined
   - No evaluation criteria
   - Not integrated with PMS

5. **CER Update Failures**
   - CER not updated with new data
   - PMCF results not integrated
   - Benefit-risk not updated

### Best Practices

1. **Start Clinical Strategy Early**
   - Define clinical evidence needs in design
   - Plan PMCF during development
   - Budget for clinical investigations

2. **Use Systematic Methods**
   - Follow MEDDEV 2.7/1 Rev 4
   - Document all decisions
   - Maintain audit trail

3. **Engage Clinical Experts**
   - Use qualified clinical evaluators
   - Consult medical specialists
   - Get Notified Body input early

4. **Keep CER Current**
   - Update with new data
   - Monitor literature
   - Integrate PMCF results
