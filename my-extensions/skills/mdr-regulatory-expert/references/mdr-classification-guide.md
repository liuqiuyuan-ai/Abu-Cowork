## Classification Principles

### Key Factors
- **Device Duration**: Transient (<60 min), Short-term (>60 min, <30 days), Long-term (>30 days), Permanent
- **Invasiveness**: Non-invasive, Invasive (surgically), Implantable
- **Active Device**: Yes/No
- **Body System Affected**: Anatomical, Physiological
- **Risk Level**: Based on intended use and potential harm

### Classification Classes

| Class | Risk Level | Conformity Assessment |
|-------|------------|----------------------|
| I | Low | Self-certification (Annex II & IV) |
| Is | Low (sterile) | Notified Body involvement required |
| Im | Low (measuring) | Notified Body involvement required |
| Ir | Low (reusable) | Notified Body involvement required |
| IIa | Low-Medium | Notified Body involvement (Annex V, VII, IX) |
| IIb | Medium-High | Notified Body involvement (Annex VI, IX, X) |
| III | High | Prior review by Notified Body required |

## Classification Rules (Annex VIII)

### Rule 1-5: Non-Invasive Devices

**Rule 1** (Class I)
- Non-invasive devices for channeling or storing blood, body liquids, tissues
- Exception: Blood bags (IIa)

**Rule 2** (Class IIa)
- Non-invasive devices modifying biological composition of blood or body liquids
- Devices for wound healing

**Rule 3** (Class IIa)
- Non-invasive devices for diagnosis/treatment (electromagnetic radiation)
- Examples: X-ray equipment, ultrasound

**Rule 4** (Class I)
- Other non-invasive devices
- Exceptions may increase classification

**Rule 5** (Class I/IIa)
- Non-invasive devices with measuring function: Class IIa
- Others: Class I

### Rule 6-9: Invasive Devices

**Rule 6** (Transient invasive - Class IIa)
- Surgically invasive devices for transient use (<60 minutes)
- Exceptions: sutures, clips (I)

**Rule 7** (Short-term invasive - Class IIa)
- Surgically invasive devices for short-term use
- Exceptions: breast implants, hip implants (III)

**Rule 8** (Long-term/Implantable - Class IIb/III)
- Implantable and long-term surgically invasive devices
- Cardiovascular/CNS implants: Class III
- Others: Class IIb
- Exceptions: sutures, dental implants, hearing aids (IIa/IIb)

### Rule 9-13: Active Devices

**Rule 9** (Therapeutic - Class IIa/IIb)
- Active devices for diagnosis/treatment: Class IIa
- Active devices emitting ionizing radiation: Class IIb
- Active devices controlling/monitoring: Class IIa

**Rule 10** (Diagnostic - Class IIa)
- Active devices for in vitro examination: Class IIa
- Examples: blood analyzers, X-ray equipment

**Rule 11** (Active devices - Class IIa/IIb)
- Software providing diagnostic/ therapeutic decision: Class IIa
- Software monitoring physiological parameters: Class IIa
- Monitoring/displaying vital signs (critical): Class IIb

**Rule 12** (Class I)
- Other active devices

### Rule 13-18: Special Rules

**Rule 13** (Class III)
- All implantable devices
- Active implantable devices
- Contraceptive implants

**Rule 14** (Class IIb/III)
- Devices containing medicinal products: Class IIb/III
- Devices incorporating biological material: Class III

**Rule 15** (Class IIa/IIb)
- Devices for disinfection/sterilization: Class IIa
- Devices for sterilization of invasive devices: Class IIb

**Rule 16** (Class IIa)
- Devices for diagnosis and monitoring of contraception

**Rule 17** (Class IIa)
- Devices manufactured from animal tissue (non-viable)

**Rule 18** (Class IIa)
- Devices for cleaning of non-invasive devices

## Device Categories

### Implantable Devices (Rule 13)
- All implantable devices: Class III
- Cardiovascular implants: Class III
- Orthopedic implants: Class IIb/III

### Active Devices
- Diagnostic imaging: Class IIa
- Therapeutic lasers: Class IIb
- MRI equipment: Class IIb

### Software as Medical Device (SaMD)
- See MDCG 2019-11

## Classification Process

### Step 1: Identify Intended Use
- Determine intended purpose
- Identify patient population
- Define clinical benefit claims

### Step 2: Apply Classification Rules
1. Check if device is covered by special rules (13-18)
2. Determine invasiveness and duration
3. Apply appropriate rule(s)
4. Consider exceptions and clarifications

### Step 3: Document Justification
- Record classification rationale
- Reference applicable rules
- Consider Notified Body input if needed

### Step 4: Validate Classification
- Confirm with Notified Body for Class IIa/IIb/III
- Request NB opinion for borderline cases

## Software Classification

### MDCG 2019-11 Guidance
- Follows classification rules with modifications
- Software that drives or influences device: Class of device
- Standalone software: Rules apply with modified interpretation

### Software Categories
- **Information**: Class I/IIa depending on decision impact
- **Drive/Influence**: Class of device
- **Clinical Decision**: Class IIa minimum, Class IIb/III if critical

## Borderline Cases

### When to Seek Clarification
- Novel device types
- Combination products
- Devices at classification boundaries
- Devices with multiple intended uses

### Process for Resolution
1. Document classification rationale
2. Request Notified Body opinion
3. Consider competent authority consultation
4. Maintain documentation of decision
