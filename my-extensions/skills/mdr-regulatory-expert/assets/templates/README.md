# Templates Directory

This directory contains templates for MDR regulatory compliance documentation.

## Available Templates

| Template | Description |
|----------|-------------|
| mdr-classification-decision.md | MDR device classification decision template |
| technical-file-checklist.md | Technical file preparation checklist |
| clinical-evaluation-report.md | Clinical evaluation report template |
| pmcf-plan-template.md | PMCF plan template |
| psur-template.md | Periodic safety update report template |
| gspr-checklist.md | General safety and performance requirements checklist |
| README.md | This file |

## Usage

These templates should be used when:
- Making MDR classification decisions
- Preparing technical documentation
- Conducting clinical evaluations
- Developing PMCF plans
- Preparing PSURs
