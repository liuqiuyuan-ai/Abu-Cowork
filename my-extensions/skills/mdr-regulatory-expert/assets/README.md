# Assets Directory

This directory contains assets for the MDR Regulatory Expert skill.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| templates/ | Technical file and regulatory templates |

## Usage

Assets are used to support MDR regulatory compliance activities, including:
- MDR classification decisions
- Technical file preparation
- Clinical evaluation
- Post-market surveillance
- GSPR compliance

## Asset Types

- Documentation templates (Markdown)
- Checklist templates
- Report templates
