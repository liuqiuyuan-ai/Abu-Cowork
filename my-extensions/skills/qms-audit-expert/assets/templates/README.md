# Templates Directory

This directory contains templates for QMS audit documentation.

## Available Templates

| Template | Description |
|----------|-------------|
| audit-plan-template.md | Audit plan template |
| audit-report-template.md | Audit report template |
| nonconformity-report-template.md | Nonconformity report template |
| corrective-action-form.md | Corrective action form |

## Usage

These templates should be used when:
- Planning an internal audit
- Reporting audit findings
- Documenting nonconformities
- Tracking corrective actions

## Customization

Templates can be customized to meet specific organizational needs while maintaining compliance with ISO 13485:2016 requirements.
