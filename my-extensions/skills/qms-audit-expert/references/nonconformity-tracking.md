# Nonconformity Tracking and Management

This document provides guidelines for tracking and managing nonconformities identified during audits.

## 1. Nonconformity Definition

A nonconformity is the non-fulfillment of a requirement. This includes:
- Non-compliance with ISO 13485:2016
- Non-compliance with internal procedures
- Non-compliance with regulatory requirements
- Deviations from approved specifications

## 2. Nonconformity Severity Levels

### Major Nonconformity
- Could affect product safety or efficacy
- Could lead to regulatory non-compliance
- Systemic failure in QMS
- Missing critical documentation

### Minor Nonconformity
- Does not affect product safety
- Isolated incident
- Minor procedural deviation
- Administrative issues

### Observation
- Opportunity for improvement
- Not a nonconformity but worth addressing
- Best practice recommendation

## 3. Nonconformity Tracking Process

### Step 1: Identification
- Document nonconformity during audit
- Record:
  - Description
  - ISO clause reference
  - Evidence
  - Severity
  - Area affected

### Step 2: Documentation
- Complete Nonconformity Report Form
- Include:
  - Nonconformity ID
  - Audit ID
  - Date identified
  - Auditor name

### Step 3: Root Cause Analysis
- Use appropriate tools:
  - 5-Why Analysis
  - Fishbone Diagram
  - FMEA

### Step 4: Corrective Action
- Develop corrective action plan
- Assign responsibility
- Set target completion date

### Step 5: Implementation
- Execute corrective action
- Document implementation

### Step 6: Verification
- Verify effectiveness
- Document verification results
- Close nonconformity if effective

## 5. Status Definitions

- **Open:** Nonconformity identified, no action taken
- **In Progress:** Corrective action plan developed and being implemented
- **Pending Verification:** Corrective action implemented, awaiting verification
- **Closed:** Corrective action verified effective
- **Reopened:** Corrective action not effective, needs rework

## 6. Reporting Requirements

- Monthly nonconformity status report to management
- Trend analysis of nonconformities
- Quarterly summary for management review

## 7. Best Practices

1. **Timely Response:** Address nonconformities promptly
2. **Root Cause Focus:** Identify and address underlying causes
3. **Documentation:** Maintain complete records
4. **Communication:** Keep all relevant parties informed
5. **Follow-up:** Ensure corrective actions are verified
6. **Trend Analysis:** Use data to drive improvements
