# QMS Assets Directory

This directory contains additional resources and materials to support QMS implementation and maintenance.

## Available Assets

### Training Materials
- `training-materials/` - ISO 13485 training presentations and materials
  - QMS overview presentations
  - Document control training
  - Process-specific training modules
  - Competency assessment tools

### Audit Forms
- `audit-forms/` - Internal audit report and checklist templates
  - Audit checklists
  - Audit report templates
  - Nonconformity forms
  - Audit planning tools

### Process Flowcharts
- `process-flowcharts/` - Visual process documentation templates
  - QMS process maps
  - Process interaction diagrams
  - Workflow diagrams
  - Decision trees

### Document Templates
- `document-templates/` - Standardized document templates and formats
  - Quality manual template
  - Procedure templates
  - Work instruction templates
  - Form templates

### Change Control Forms
- `change-control-forms/` - Change request and approval documentation templates
  - Change request forms
  - Change approval forms
  - Change impact assessment templates
  - Change verification checklists

### Audit Checklists
- `audit-checklists/` - Document control compliance verification checklists
  - Clause-specific checklists
  - Process audit checklists
  - System audit checklists
  - Compliance verification tools

## Usage

1. Use training materials to develop QMS training programs
2. Adapt audit forms for your organization's audit process
3. Customize flowcharts to document your QMS processes
4. Use document templates for consistent document creation
5. Implement change control forms for systematic change management
6. Utilize audit checklists for compliance verification
