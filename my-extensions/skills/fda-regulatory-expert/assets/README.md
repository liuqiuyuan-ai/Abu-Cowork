# Assets Directory

This directory contains assets for the FDA Regulatory Expert skill.

## Subdirectories

| Directory | Description |
|-----------|-------------|
| templates/ | Regulatory submission templates |

## Usage

Assets are used to support FDA regulatory compliance activities, including:
- FDA pathway analysis
- QSR compliance assessment
- HIPAA compliance assessment
- 510(k) submission preparation

## Asset Types

- Documentation templates (Markdown)
- Checklist templates
- Form templates
