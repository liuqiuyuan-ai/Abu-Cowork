## Device Classification

### Class I
- Low risk devices
- General controls sufficient
- Most are exempt from 510(k)
- Examples: bandages, examination gloves, tongue depressors

### Class II
- Moderate risk devices
- Special controls required
- Most require 510(k) clearance
- Examples: pacemakers, hearing aids, pregnancy tests

### Class III
- High risk devices
- PMA required
- Examples: implantable heart valves, artificial hearts, breast implants

## FDA Pathways Overview

| Pathway | Description | Classification | Review Time |
|---------|-------------|---------------|-------------|
| 510(k) | Substantial equivalence | Class I/II | 90-180 days |
| PMA | Safety/effectiveness | Class III | 6-12+ months |
| De Novo | Novel devices | Class I/II (novel) | 150 days |
| IDE | Clinical investigation | All classes | 30 days |

## 510(k) Clearance

### Requirements
- Demonstrate substantial equivalence to predicate device
- Performance data
- Labeling
- Biocompatibility data (if applicable)
- Software validation (if applicable)

### Submission Components
1. Cover letter
2. Table of contents
3. Indications for use
4. 510(k) summary or statement
5. Substantial equivalence comparison
6. Performance data
7. Labeling

### Predicate Device Selection
- Legally marketed device
- Similar intended use
- Similar technological characteristics
- Multiple predicates may be used

## Premarket Approval (PMA)

### Requirements
- Clinical trial data
- Comprehensive safety and effectiveness data
- Manufacturing information
- Risk analysis

### PMA Application Components
1. Application form
2. Summary of safety/effectiveness
3. Clinical investigation reports
4. Non-clinical laboratory studies
5. Manufacturing information
6. Device description
7. Labeling
8. Risk analysis

### PMA Supplements
- Required for changes affecting safety/effectiveness
- Types: Design change, manufacturing change, labeling change

## De Novo Classification

### Eligibility
- No legally marketed predicate device
- Novel technology
- Not automatically Class III

### Submission Requirements
1. De Novo request form
2. Indications for use
3. Safety and effectiveness data
4. Risk analysis
5. Benefit-risk assessment
6. Proposed classification

## Investigational Device Exemption (IDE)

### Purpose
- Allows clinical investigation of devices not yet approved
- Required before conducting clinical trials

### IDE Application Components
1. IDE application form
2. Investigational plan
3. Investigator's brochure
4. IRB approval letter
5. Manufacturing information
6. Labeling
7. Safety monitoring plan

### IDE Types
- **Significant risk (SR)** - Higher risk devices requiring FDA review
- **Non-significant risk (NSR)** - Lower risk devices, FDA notified but not reviewed

## Pathway Decision Flowchart

```
Start → Classified? → Class III → PMA
       ↓
       Class I/II → Has Predicate? → Yes → 510(k)
                   ↓
                   No → Novel? → Yes → De Novo
                   ↓
                   No → 510(k)
                   
       Needs Clinical Trials? → Yes → IDE
```

## Key Considerations

1. **Start Early**: Begin FDA planning in early development
2. **Predicates**: Identify predicate devices early
3. **Pre-Submission**: Consider pre-submission meeting with FDA
4. **Consult Experts**: Engage FDA-registered regulatory consultants
5. **Stay Updated**: Monitor FDA guidance documents
