## 1. GMP概述

### 1.1 GMP定义

药品生产质量管理规范（Good Manufacturing Practices, GMP）是药品生产和质量管理的基本准则，确保药品生产过程的质量控制和质量保证。

### 1.2 NMPA GMP法规体系

| 法规名称 | 编号 | 适用范围 |
|----------|------|----------|
| 《药品生产质量管理规范》 | 国家药监局令第27号 | 药品生产企业 |
| 《医疗器械生产质量管理规范》 | 国家药监局令第74号 | 医疗器械生产企业 |
| 《药品GMP检查要点指南》 | - | GMP检查指导 |
| 《医疗器械GMP检查要点指南》 | - | GMP检查指导 |

### 1.3 GMP核心原则

1. **质量源于设计（QbD）**
2. **全过程控制**
3. **风险管理**
4. **持续改进**
5. **数据完整性**
6. **可追溯性**

## 2. 质量管理体系

### 2.1 QMS要求

| 要素 | 要求 |
|------|------|
| 质量方针 | 由最高管理者批准发布 |
| 质量目标 | 可测量、可监控 |
| 组织架构 | 明确职责分工 |
| 质量负责人 | 独立行使职权 |
| 管理评审 | 定期评审QMS有效性 |

### 2.2 质量手册内容

1. 企业概况
2. 质量方针和目标
3. 组织架构图
4. 部门职责描述
5. 质量体系要素
6. 质量管理制度

## 3. 机构与人员

### 3.1 人员资质要求

| 岗位 | 资质要求 |
|------|----------|
| 企业负责人 | 药学或相关专业背景 |
| 质量负责人 | 药学或相关专业，3年以上经验 |
| 生产负责人 | 药学或相关专业，3年以上经验 |
| 质量受权人 | 药学或相关专业，5年以上经验 |
| 检验人员 | 相关专业，培训合格 |

### 3.2 培训要求

| 培训类型 | 要求 |
|----------|------|
| 入职培训 | GMP基础知识、岗位职责 |
| 岗位培训 | 专业技能、操作规程 |
| 继续培训 | 法规更新、新技术 |
| 培训记录 | 培训内容、考核结果 |

### 3.3 人员健康管理

- 建立健康档案
- 定期体检
- 传染病患者不得从事直接接触药品的工作

## 4. 厂房与设施

### 4.1 厂房设计要求

| 区域 | 要求 |
|------|------|
| 生产区 | 布局合理，流程顺畅 |
| 仓储区 | 分区存放，温湿度控制 |
| 质量控制区 | 独立设置，避免污染 |
| 辅助区 | 办公、维修、更衣等 |

### 4.2 洁净区要求

| 洁净级别 | 适用范围 | 悬浮粒子要求 |
|----------|----------|--------------|
| A级 | 高风险操作区 | ≥0.5μm: ≤3520/m³ |
| B级 | 无菌配制、灌装 | ≥0.5μm: ≤352000/m³ |
| C级 | 无菌药品生产 | ≥0.5μm: ≤3520000/m³ |
| D级 | 非无菌药品生产 | ≥0.5μm: ≤35200000/m³ |

### 4.3 环境监测

- 悬浮粒子监测
- 沉降菌/浮游菌监测
- 温湿度监测
- 压差监测

## 5. 设备管理

### 5.1 设备验证

| 验证类型 | 要求 |
|----------|------|
| IQ（安装确认） | 设备安装符合设计要求 |
| OQ（运行确认） | 设备运行参数符合要求 |
| PQ（性能确认） | 设备性能满足生产要求 |

### 5.2 设备维护

- 建立设备维护计划
- 定期保养和维修
- 维护记录完整
- 设备标识清晰

### 5.3 校准要求

- 计量器具定期校准
- 校准证书有效
- 校准标识清晰

## 6. 文件管理

### 6.1 文件分类

| 文件类型 | 内容 |
|----------|------|
| 质量手册 | QMS总体描述 |
| 程序文件 | 管理性文件 |
| 操作规程 | 作业指导书 |
| 记录 | 生产、检验等记录 |

### 6.2 文件控制要求

| 环节 | 要求 |
|------|------|
| 起草 | 指定人员起草 |
| 审核 | 相关部门审核 |
| 批准 | 授权人员批准 |
| 分发 | 受控发放 |
| 变更 | 变更控制程序 |
| 作废 | 收回并销毁 |

### 6.3 记录管理要求

- 记录真实、准确、完整
- 使用不易擦除的书写工具
- 记录保存期限符合要求
- 电子记录符合数据完整性要求

## 7. 物料管理

### 7.1 物料采购

| 环节 | 要求 |
|------|------|
| 供应商选择 | 质量评估 |
| 供应商审核 | 定期审核 |
| 采购合同 | 明确质量要求 |

### 7.2 物料验收

- 核对物料名称、规格、批号
- 检查包装完整性
- 取样检验
- 合格后入库

### 7.3 物料储存

| 储存条件 | 要求 |
|----------|------|
| 温湿度 | 符合物料要求 |
| 分区存放 | 合格、不合格、待验分开 |
| 有效期管理 | 先进先出 |
| 特殊物料 | 危险品、易制毒化学品特殊管理 |

### 7.4 物料追溯

- 批号管理
- 物料流向记录
- 追溯至原材料

## 8. 生产管理

### 8.1 工艺验证

| 验证类型 | 要求 |
|----------|------|
| 工艺验证 | 首次验证、变更验证 |
| 清洁验证 | 清洁方法验证 |
| 灭菌验证 | 灭菌工艺验证 |

### 8.2 批生产记录

批生产记录应包含：
- 产品名称、批号、生产日期
- 生产工序记录
- 中间产品检验记录
- 操作人员签名
- 异常情况处理记录

### 8.3 生产控制

| 控制项目 | 要求 |
|----------|------|
| 配料 | 双人复核 |
| 称量 | 精确称量，记录完整 |
| 工艺参数 | 监控并记录 |
| 环境控制 | 符合洁净级别要求 |

### 8.4 标签管理

- 标签设计审核
- 标签发放记录
- 剩余标签回收
- 防止混淆

## 9. 质量控制

### 9.1 实验室管理

| 要求 | 说明 |
|------|------|
| 人员资质 | 专业培训合格 |
| 设备校准 | 定期校准 |
| 检验方法 | 验证确认 |
| 标准品 | 溯源至国家标准 |

### 9.2 检验流程

```
检验流程
├── 取样
├── 检验
├── 记录
├── 审核
└── 报告
```

### 9.3 成品放行

- 质量受权人批准
- 检验结果符合标准
- 批记录完整
- 无重大偏差

## 10. 质量保证

### 10.1 投诉处理

| 流程 | 要求 |
|------|------|
| 投诉接收 | 记录投诉内容 |
| 调查分析 | 调查原因 |
| 处理措施 | 采取纠正措施 |
| 反馈回复 | 回复投诉人 |

### 10.2 不合格品管理

| 流程 | 要求 |
|------|------|
| 识别 | 标识不合格品 |
| 隔离 | 隔离存放 |
| 评审 | 质量部门评审 |
| 处置 | 返工、销毁或让步接收 |

### 10.3 CAPA系统

| 环节 | 要求 |
|------|------|
| 纠正措施 | 解决已发生问题 |
| 预防措施 | 防止问题发生 |
| 验证 | 措施有效性验证 |
| 记录 | CAPA记录完整 |

## 11. 自检与持续改进

### 11.1 内部审核

- 定期进行内部审核
- 审核范围覆盖所有GMP要素
- 发现问题及时整改
- 审核报告提交管理层

### 11.2 管理评审

| 输入 | 内容 |
|------|------|
| 内部审核结果 | 审核报告 |
| 投诉处理 | 投诉统计 |
| 产品质量 | 质量指标 |
| 纠正措施 | CAPA状态 |

### 11.3 持续改进

- 建立质量指标体系
- 监控质量趋势
- 实施改进项目
- 定期评估效果

## 附录：GMP检查常见缺陷

| 类别 | 常见缺陷 |
|------|----------|
| 文件管理 | 文件未批准、记录不完整 |
| 设备管理 | 设备未验证、校准过期 |
| 生产管理 | 批记录不完整、工艺参数未监控 |
| 质量控制 | 检验方法未验证、标准品管理不当 |
| 物料管理 | 物料标识不清、储存条件不符合 |
| 人员培训 | 培训记录不全、未定期培训 |
