## 1. 上市后监管概述

### 1.1 上市后监管定义

上市后监管（Post-Market Surveillance, PMS）是指医疗器械或药品上市后，对其安全性、有效性进行持续监测和管理的活动。

### 1.2 NMPA上市后监管法规

| 法规名称 | 编号 | 适用范围 |
|----------|------|----------|
| 《医疗器械不良事件监测和再评价管理办法》 | 国家药监局令第1号 | 医疗器械 |
| 《药品不良反应报告和监测管理办法》 | 卫生部令第81号 | 药品 |
| 《医疗器械召回管理办法》 | 国家药监局令第29号 | 医疗器械 |
| 《药品召回管理办法》 | 国家药监局令第29号 | 药品 |

### 1.3 上市后监管目的

1. 及时发现产品安全隐患
2. 评估产品风险收益比
3. 采取必要的风险控制措施
4. 保障公众用药用械安全

## 2. 不良事件报告

### 2.1 不良事件定义

| 类型 | 定义 |
|------|------|
| 医疗器械不良事件 | 医疗器械在正常使用情况下发生的导致或可能导致人体伤害的各种有害事件 |
| 药品不良反应 | 合格药品在正常用法用量下出现的与用药目的无关的有害反应 |

### 2.2 报告分类

| 报告类型 | 定义 | 报告时限 |
|----------|------|----------|
| 严重不良事件 | 导致死亡、严重伤害或危及生命 | 15个工作日 |
| 一般不良事件 | 其他不良事件 | 30个工作日 |
| 境外不良事件 | 在境外发生的不良事件 | 30个工作日 |

### 2.3 报告流程

```
不良事件报告流程
├── 发现不良事件
├── 初步评估
├── 收集信息
│   ├── 患者信息
│   ├── 产品信息
│   └── 事件描述
├── 报告提交
│   ├── 在线报告
│   └── 纸质报告（如适用）
├── 调查分析
│   ├── 原因分析
│   └── 风险评估
└── 采取措施
    ├── 风险控制
    └── 信息通报
```

### 2.4 报告内容要求

| 项目 | 内容 |
|------|------|
| 基本信息 | 报告单位、报告人、报告日期 |
| 患者信息 | 年龄、性别、诊断 |
| 产品信息 | 名称、型号、批号、序列号 |
| 事件信息 | 发生时间、地点、描述 |
| 处理情况 | 医疗措施、患者转归 |
| 初步分析 | 可能原因、风险评估 |

## 3. 市场监测

### 3.1 市场监测内容

| 监测类型 | 内容 |
|----------|------|
| 产品质量监测 | 产品性能、可靠性 |
| 投诉处理 | 用户投诉、反馈 |
| 舆情监测 | 媒体报道、网络舆情 |
| 行业动态 | 同类产品安全信息 |

### 3.2 投诉处理流程

```
投诉处理流程
├── 投诉接收
│   ├── 电话投诉
│   ├── 书面投诉
│   └── 网络投诉
├── 投诉记录
│   ├── 投诉人信息
│   ├── 投诉内容
│   └── 投诉日期
├── 调查分析
│   ├── 核实情况
│   ├── 原因分析
│   └── 责任判定
├── 处理回复
│   ├── 解决方案
│   ├── 回复投诉人
│   └── 记录归档
└── 跟踪验证
    ├── 措施有效性
    └── 投诉人满意度
```

### 3.3 趋势分析

- 定期汇总分析不良事件数据
- 识别潜在风险信号
- 评估风险趋势
- 提出风险控制建议

## 4. 产品召回

### 4.1 召回分级

| 级别 | 定义 | 召回时限 |
|------|------|----------|
| **一级召回** | 使用该产品可能导致严重健康危害或死亡 | 24小时内 |
| **二级召回** | 使用该产品可能导致暂时或可逆的健康危害 | 48小时内 |
| **三级召回** | 使用该产品不会引起健康危害，但存在其他问题 | 72小时内 |

### 4.2 召回流程

```
产品召回流程
├── 召回启动
│   ├── 发现问题
│   ├── 风险评估
│   └── 召回决定
├── 召回实施
│   ├── 通知经销商/用户
│   ├── 收回产品
│   └── 记录追踪
├── 召回评估
│   ├── 召回效果评估
│   └── 原因分析
└── 召回报告
    ├── 提交NMPA
    └── 信息公开
```

### 4.3 召回报告内容

| 项目 | 内容 |
|------|------|
| 召回基本信息 | 产品名称、型号、批号、数量 |
| 召回原因 | 问题描述、风险评估 |
| 召回级别 | 一级/二级/三级 |
| 召回措施 | 通知方式、回收方式 |
| 召回进展 | 已回收数量、未回收数量 |
| 后续措施 | 纠正措施、预防措施 |

## 5. 定期安全更新报告

### 5.1 PSUR定义

定期安全更新报告（Periodic Safety Update Report, PSUR）是对上市后产品安全性进行定期汇总分析的报告。

### 5.2 PSUR提交周期

| 产品类型 | 提交周期 |
|----------|----------|
| 医疗器械（高风险） | 每年 |
| 医疗器械（中风险） | 每2年 |
| 医疗器械（低风险） | 每5年 |
| 药品 | 每年 |

### 5.3 PSUR内容要求

| 章节 | 内容 |
|------|------|
| 执行摘要 | 主要安全问题和措施 |
| 产品信息 | 产品描述、适应症 |
| 全球市场情况 | 销售地区、使用量 |
| 安全性数据 | 不良事件汇总、趋势分析 |
| 风险评估 | 风险收益比评估 |
| 风险管理更新 | 风险控制措施更新 |
| 结论与建议 | 安全性结论、改进建议 |

## 6. 再注册要求

### 6.1 再注册定义

再注册是指医疗器械或药品注册证到期前，向NMPA申请延续注册的过程。

### 6.2 再注册申请时间

- 注册证有效期届满前6个月提出申请
- 逾期未申请的，注册证自动失效

### 6.3 再注册申请资料

| 资料类型 | 内容 |
|----------|------|
| 再注册申请表 | 在线填写并提交 |
| 注册证原件 | 原注册证书 |
| 产品变化情况 | 上市后变更说明 |
| 质量体系证明 | GMP证书或检查报告 |
| 上市后监测报告 | 不良事件汇总、PSUR |
| 其他资料 | 如有变更需提供相关证明 |

### 6.4 再注册流程

```
再注册流程
├── 资料准备
│   ├── 申请表
│   ├── 证明文件
│   └── 监测报告
├── 申请提交
│   ├── 在线申请
│   └── 纸质资料递交
├── 审评审批
│   ├── 形式审查
│   ├── 技术审评
│   └── 行政审批
└── 领取新证
    ├── 新注册证书
    └── 证书有效期延续
```

## 7. 常见问题

### Q1：所有不良事件都需要报告吗？

**A:**
- 是的，所有不良事件都需要报告
- 严重不良事件需在15个工作日内报告
- 一般不良事件需在30个工作日内报告

### Q2：如何判断不良事件与产品的因果关系？

**A:**
- 评估时间关联性
- 评估产品使用情况
- 排除其他可能原因
- 参考同类产品的安全信息

### Q3：产品召回后如何处理召回产品？

**A:**
- 根据风险程度决定处理方式
- 可选择：销毁、返工、更换、退款
- 处理方式需经NMPA批准

### Q4：PSUR和年度报告有什么区别？

**A:**
- PSUR是针对产品安全性的专业报告
- 年度报告是企业年度经营情况报告
- PSUR内容更侧重于安全数据和风险评估

### Q5：再注册时如果产品有变更怎么办？

**A:**
- 如果是重大变更，需先申请变更注册
- 如果是微小变更，可在再注册时一并说明
- 变更情况需在申请资料中详细说明
